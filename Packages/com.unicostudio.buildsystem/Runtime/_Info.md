# Runtime (UnicoStudio.BuildSystem)

Addressables versioning types shared by the Addressables profile bindings and the build stages, plus
the project-level settings asset.

Contents:
- `AddressablesProfile` — enum `{ Development, Test, Production }`. The single source of truth for profile identity; each value's name must match an Addressables profile name in the host game.
- `AddressablesProfilePaths` — the six properties the host's Addressables profile variables bind to by name: `Remote{Build,Load}{Development,Test,Production}Path`. `Build*` composes against the package's own local staging convention (`UnicoBuildPaths.BUILD_PATH_BASE`); `Load*` composes against `BuildSystemSettings.RequireRemoteLoadRoot()` — the host's data. The whole file is `#if UNITY_EDITOR`: these are `[...]` profile variables, evaluated at BUILD time in the editor and baked into the catalog, never resolved in a player. A NAMESPACED PACKAGE TYPE RESOLVES because Addressables splits a `[Type.Member]` token on the LAST dot and calls `Assembly.GetType` on the left half over every loaded assembly — the reason this can live in the package instead of a class each host game copies.
- `BuildSystemSettings` — project-level settings `ScriptableObject` (same `Assets/`-scoped discovery contract as the version store). Optional for player-only hosts; **required for hosts that build Addressables content**, which is where `RemoteLoadRoot` lives. `TestModeDefine` renames the kind-ruled test define per game; `EffectiveTestModeDefine` falls back to `TEST_MODE` on blank/invalid values so the Test/Release safety rule survives misconfiguration. `RemoteLoadRoot` holds this game's remote content root; `IsValidRemoteLoadRoot` is its validity rule — an `http://`/`https://` scheme test that is ORDINAL and case-INSENSITIVE (schemes are case-insensitive per RFC 3986, while culture-sensitive matching would treat some zero-width characters as ignorable and accept a root no CDN can serve). The ENDING is deliberately unconstrained. `EffectiveRemoteLoadRoot` returns the trimmed value or `null`; `RequireRemoteLoadRoot()` delegates to it and throws with two DISTINCT messages — one for "no asset exists", one naming the asset path and the rejected value. Also owns `IsValidDefine` — the single validity rule for define tokens. Editor callers resolve via `ResolveTestModeDefine()`.
- `AddressablesVersionStore` — a `ScriptableObject` holding the integer remote content version. Writable (bumped by `ApplyVersionStage`). Discovered via `AssetDatabase.FindAssets` scoped to `Assets/` (each game commits exactly one instance; convention `Assets/Settings/Build/`). Multiple instances log an error and pick deterministically.
- `UnicoBuildPaths` — composes `{pathBase}{version}/{profile}/{buildTarget}` paths. `BUILD_PATH_BASE` (`ServerData/v`) is the shared local staging convention. `RequireVersion()` THROWS if the store asset is missing — deliberate fail-loud; a silent fallback version would publish content to the wrong remote path.

Rules:
- The game-specific CDN root is DATA, not host code: `BuildSystemSettings.RemoteLoadRoot`. Adopting the package for Addressables is a settings asset plus six profile strings pointing at `AddressablesProfilePaths` — no host class of any kind.
- `RemoteLoadRoot` has NO fail-safe default, unlike `TestModeDefine`. A wrong-but-present define is safer than none; a guessed CDN root would publish content to, or load it from, the wrong host — so an unusable value reports "not usable" and `RequireRemoteLoadRoot()` throws. The Addressables profile evaluator SWALLOWS a getter's exception and substitutes the token's own text, so that throw surfaces as an unresolved binding, which is what `ProfileBindingRule` and `RemotePathCheck` exist to catch.
- Callers that must tolerate a missing store use `AddressablesVersionStore.LoadOrNull()` (panel display, snapshot capture); build paths go through `RequireVersion()` and fail loud.
- Convert `AddressablesProfile` to a profile-name string only at the Addressables API boundary (`AddressablesStage`); never store profile identity as a string elsewhere.
